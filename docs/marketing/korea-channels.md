```
제목: [서비스 소개] 195개국 분쟁·안보 실시간 모니터링 플랫폼 'WeWantPeace' 출시

안녕하세요, 에디터님.

195개국의 분쟁·안보 상황을 AI로 실시간 모니터링하는 플랫폼
'WeWantPeace'(https://www.wewantpeace.live)를 소개드립니다.

■ 서비스 개요
- 전 세계 195개국 분쟁·안보 이벤트를 AI(GPT-4o-mini)가 자동 수집·분류·시각화
- 실시간 지도, 심각도 분석, 국가별 긴장도 리포트 제공
- Freemium SaaS 모델 (웹 + PWA + Android)

■ 기술 스택
- Next.js, FastAPI, Celery, PostgreSQL, AI 파이프라인
- 1인 한국 인디 개발자가 기획부터 운영까지 전 과정 담당

■ 왜 만들었나
2024년 12월 한국 계엄 사태 당시, 국제 안보 관점에서 전체 상황을
실시간으로 파악하기 어려웠습니다. 기존 도구는 고가 유료 플랫폼이거나
느린 학술 데이터셋, 또는 구조 없는 뉴스 피드뿐이었습니다.
WeWantPeace는 누구나 "지금 어디서 무슨 일이 벌어지고 있는지"를
한눈에 파악할 수 있도록 설계했습니다.

인터뷰나 추가 자료가 필요하시면 언제든 연락 주세요.
감사합니다.

김신혁
WeWantPeace 개발자
이메일: krshin7@naver.com
```

### Show GN 게시글

```
제목: Show GN: WeWantPeace - 195개국 분쟁·안보 실시간 모니터링 플랫폼

안녕하세요, 1인 개발자입니다.

전 세계 195개국의 분쟁·안보 상황을 실시간으로 모니터링하는
WeWantPeace (https://www.wewantpeace.live)를 만들었습니다.

■ 무엇을 하는 서비스인가?
- 60+ 글로벌 뉴스 소스에서 분쟁·안보 이벤트를 3-5분 간격 자동 수집
- GPT-4o-mini로 국가, 주제, 심각도 자동 분류 후 클러스터링
- 지도 기반 시각화 + 국가별 긴장도 지수(Tension Index) + KScore

■ 왜 만들었나?
계엄 사태 당시, 국제 뉴스가 파편적이라 전체 상황을 파악하기
어려웠습니다. 한 곳에서 모든 분쟁 상황을 볼 수 있는 서비스가
필요하다고 느꼈습니다.

■ 기술 스택
- Frontend: Next.js 14 (App Router) + Tailwind, Vercel
- Backend: FastAPI + Celery + PostgreSQL(Supabase), Railway
- Data: RSS, GDELT, ACLED, USGS 지진 API
- AI: GPT-4o-mini 분류/요약 파이프라인
- 공개 API 제공 (무료 tier 포함)

피드백 환영합니다!
```
