# 기자 콜드 이메일 템플릿

> **대상**: 수집된 1,198명 기자 (10개 매체)
> **목표**: WeWantPeace를 취재 도구로 소개 → 사용자 확보 + 보도 유도
> **핵심 전략**: "판매"가 아니라 "취재에 쓸 수 있는 무료 도구 공유"

## A안: 국제부/정치부 기자 (핵심 타겟)

### 제목 후보 (A/B 테스트)
1. `[도구 공유] 분쟁 취재할 때 쓸 만한 실시간 모니터링 플랫폼`
2. `이란-미국 확전, 로이터보다 24시간 빨리 감지한 도구`
3. `기자님 기사에서 영감받아 만든 분쟁 모니터링 도구입니다`

### 본문

```
{이름} 기자님 안녕하세요.

{매체}에서 쓰신 기사 잘 읽고 있는 1인 개발자 김신혁입니다.

기자님 취재에 도움이 될 수 있을 것 같아 연락드립니다.

WeWantPeace(https://www.wewantpeace.live)는 전 세계 195개국의 분쟁·안보 이벤트를 실시간으로 수집·분류하는 무료 플랫폼입니다. 200개 이상 소스(로이터·AP·AFP + 지역 미디어 + 텔레그램 OSINT 채널)를 3~5분 간격으로 모니터링합니다.

취재에 이렇게 쓸 수 있습니다:

• 속보 선행 감지 — 3월 이란-미국 사태 때 로이터/AP보다 평균 12.9시간 먼저 감지 (사례: 하메네이 후계 구도 24.5시간 선행)
• 다수 소스 교차 확인 — 같은 사건을 몇 개 독립 소스가 보도하는지 한눈에 파악
• 국가별 긴장도 추이 — 특정 국가의 위험도 변화를 시계열 차트로 확인
• 실시간 분쟁 지도 — 전 세계 이슈를 지도 위에서 클릭 한 번으로 탐색

무료이고, 회원가입 없이 바로 쓸 수 있습니다.

혹시 이 서비스에 대해 취재하실 의향이 있으시면 인터뷰나 추가 자료도 기꺼이 드리겠습니다.

2. `호르무즈 봉쇄가 한국에 미치는 영향, 숫자로 보여주는 도구`

### 본문

```
{이름} 기자님 안녕하세요.

분쟁 이벤트가 한국 경제에 미치는 영향을 실시간으로 분석하는 무료 도구를 만들었는데, 기자님 취재에 참고가 될 것 같아 공유드립니다.

경제 취재에 활용 포인트:

• 영향 흐름 분석 — "이란 호르무즈 봉쇄 → 원유 수급 → 한국 산업" 같은 파급 경로를 시각화
• KScore(핵심영향점수) — 각 분쟁 이벤트가 한국에 미치는 영향도를 0~10점으로 수치화

• 200+ 소스 실시간 수집 — 속보 발생 시 3~5분 내 반영

무료이고 회원가입 없이 바로 사용 가능합니다.

서비스 관련 취재나 인터뷰가 필요하시면 언제든 연락 주세요.
