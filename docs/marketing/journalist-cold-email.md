## A안: 국제부/정치부 기자 (핵심 타겟)

2. `디스콰이엇 이주의 프로덕트 수상 — 1인 개발자의 분쟁 모니터링 도구`

### 본문

```
{이름} 기자님 안녕하세요.

{매체}에서 쓰신 기사 잘 읽고 있는 1인 개발자 김신혁입니다.

기자님 취재에 도움이 될 수 있을 것 같아 연락드립니다.

WeWantPeace(https://www.wewantpeace.live)는 전 세계 195개국의 분쟁·안보 이벤트를 실시간으로 수집·분류하는 무료 플랫폼입니다. 로이터·AP·BBC 같은 국제 통신사부터 지역 미디어, 텔레그램 OSINT 채널까지 66개 소스를 5분 간격으로 모니터링하고, AI가 자동으로 분류·클러스터링합니다.

최근 구글 플레이스토어 뉴스 카테고리 인기 앱 1위를 달성했고, 국내 최대 IT 프로덕트 커뮤니티 디스콰이엇에서 '이주의 프로덕트'로 선정되었습니다.

■ 취재에 이렇게 쓸 수 있습니다

• 다층 소스 동시 모니터링 — 국제 통신사, 지역 미디어, 텔레그램 OSINT 채널을 한 화면에서 비교. 3월 이란-미국 사태 때 걸프 지역 미디어와 텔레그램이 국제 통신사 확인 보도보다 수 시간~하루 먼저 신호를 보낸 사례도 있었습니다.
• 다수 소스 교차 확인 — 같은 사건을 몇 개 독립 소스가 보도하는지 한눈에 파악
• 국가별 긴장도 추이 — 특정 국가의 위험도 변화를 시계열 차트로 확인
• 실시간 분쟁 지도 — 전 세계 이슈를 지도 위에서 클릭 한 번으로 탐색

■ 실제 활용 사례

• 우크라이나-러시아: 헤르손 전선 이동을 17개 소스에서 동시 추적. 텔레그램 현지 채널이 AP/로이터보다 2~4시간 먼저 보도한 것을 확인
• 이스라엘-하마스: 가자 휴전 협상 관련 이스라엘·아랍권 미디어의 보도 온도차를 비교 분석
• 미얀마 내전: 저항군 북부 공세 확대를 지역 미디어 6개 소스에서 교차 확인
• 한반도: 북한 미사일 발사·군사 동향을 일본·미국·한국 소스에서 동시 모니터링

■ 1인 개발 스토리

2024년 12월 한국 계엄 사태를 직접 겪으면서, "지금 세계가 얼마나 위험한지" 한눈에 볼 수 있는 도구가 없다는 것을 깨달았습니다. 18세에 첫 스타트업을 시작해 연 50억 매출까지 경험한 뒤, 이번에는 수익보다 사회적 가치를 위해 혼자 개발했습니다. 현재 195개국을 실시간 커버하며, 한국어·영어 완전 지원합니다.
```
