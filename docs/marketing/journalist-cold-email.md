# 기자 콜드 이메일 템플릿

> **대상**: 수집된 1,198명 기자 (10개 매체)
> **목표**: 취재 유도 + 서비스 사용 유도
> **원칙**: 짧게, 구체적으로, 사람처럼. 불릿포인트 남발 금지.

## A안: 국제부/정치부 기자 (핵심 타겟)

### 제목 후보
1. `계엄 그날 밤, 세계 안보 상황을 볼 곳이 없었습니다`
2. `텔레그램이 AP보다 4시간 빨랐습니다 — 분쟁 취재 도구 하나 공유드립니다`
3. `이란 사태 때 걸프 현지 채널이 로이터보다 하루 먼저 움직였습니다`

### 본문

```
{이름} 기자님 안녕하세요, 김신혁이라고 합니다.

단도직입적으로 말씀드리겠습니다.

2024년 12월 계엄 그날 밤, 저는 "지금 세계가 얼마나 위험한 상태인지" 한눈에 볼 수 있는 곳이 아무 데도 없다는 걸 깨달았습니다. 그래서 직접 만들었습니다.

WeWantPeace(https://www.wewantpeace.live)입니다. 로이터, AP, BBC 같은 국제 통신사부터 현지 미디어, 텔레그램 OSINT 채널까지 66개 소스를 5분마다 긁어서 195개국 분쟁 상황을 한 화면에 보여줍니다.

기자님이 관심 가지실 만한 부분이 있습니다.

3월 이란-미국 긴장 고조 때, 저희 플랫폼에서 걸프 현지 미디어와 텔레그램 채널이 AP·로이터 확인 보도보다 수 시간에서 하루까지 먼저 신호를 보낸 걸 확인했습니다. 우크라이나 헤르손 전선 때도 텔레그램 현지 채널이 국제 통신사보다 2~4시간 빨랐고요. 같은 사건을 17개 독립 소스가 동시에 다루는 걸 한 화면에서 볼 수 있으니, 속보 판단하실 때 참고가 될 겁니다.

구글 플레이스토어 뉴스 카테고리 인기 앱 1위 찍었고, 디스콰이엇이라는 IT 프로덕트 커뮤니티에서 '이주의 프로덕트'로 뽑혔습니다. 혼자 만들었습니다.

회원가입 없이 바로 써보실 수 있습니다. 한번 들어가 보시고, 쓸 만하다 싶으시면 취재든 인터뷰든 편하게 연락 주세요.

김신혁 드림
krshin7@naver.com
```

## B안: 경제부/산업부 기자

### 제목 후보
1. `호르무즈 해협 이벤트가 급증하면 유가가 움직입니다 — 그걸 실시간으로 봅니다`
2. `분쟁이 한국 경제에 미치는 영향, 점수로 보여주는 도구를 만들었습니다`
3. `대만해협 군사 동향이 반도체 공급망에 미치는 영향, 실시간으로 추적합니다`

### 본문

```
{이름} 기자님 안녕하세요, 김신혁입니다.

기자님께 하나 여쭤봐도 될까요. 중동 기사 쓰실 때 호르무즈 해협 관련 소스 몇 개나 동시에 보십니까?

제가 만든 WeWantPeace(https://www.wewantpeace.live)는 66개 소스를 5분 간격으로 수집해서 195개국 분쟁 상황을 실시간으로 보여주는 플랫폼입니다. 혼자 만들었는데, 플레이스토어 뉴스 앱 1위까지 갔습니다.

경제 기사 쓰실 때 이런 식으로 쓸 수 있습니다.

이란-미국 긴장 고조되면 호르무즈 관련 이벤트가 플랫폼에서 먼저 급증합니다. 그게 유가에 반영되기 전에 흐름을 잡을 수 있습니다. 대만해협 쪽도 마찬가지입니다. 중국-대만 군사 동향 변화를 7개 소스에서 교차 확인할 수 있어서, 반도체 공급망 리스크 기사 쓰실 때 참고가 됩니다.

독자적으로 만든 KScore라는 지표가 있는데, 각 분쟁 이벤트가 한국에 미치는 영향도를 0~10점으로 수치화합니다. "이 사건이 한국 경제에 얼마나 영향을 주는가"를 숫자로 보여주는 건데, 해외 진출 기업이나 투자 리스크 기사에 레퍼런스로 쓸 만합니다.

무료이고 회원가입 없이 바로 들어가 보실 수 있습니다. 한번 써보시고, 괜찮다 싶으시면 편하게 연락 주세요. 인터뷰나 추가 자료 언제든 드리겠습니다.

김신혁 드림
krshin7@naver.com
```

## C안: IT/테크/문화부 기자 + 범용

### 제목 후보
1. `계엄 겪고 만든 앱이 플레이스토어 뉴스 1위를 찍었습니다`
2. `18살에 창업해서 50억 벌었는데, 지금은 혼자 분쟁 모니터링 앱을 만들고 있습니다`
3. `군사·정보기관만 하던 걸 무료로 열었더니 뉴스 앱 1위가 됐습니다`

### 본문

```
{이름} 기자님 안녕하세요, 김신혁이라고 합니다.

좀 긴 이야기를 짧게 줄여보겠습니다.

18살에 처음 사업을 시작해서 연 매출 50억까지 만들어본 적이 있습니다. 그런데 2024년 12월, 계엄 선포 뉴스를 보면서 머릿속이 하얘졌습니다. "한국이 이렇게 될 수 있구나" 싶었는데, 그보다 더 무서웠던 건 그 순간 세계 다른 곳에서 뭐가 벌어지고 있는지 알 방법이 없었다는 겁니다.

그래서 혼자 만들었습니다. WeWantPeace(https://www.wewantpeace.live)라는 플랫폼입니다.
```

## 발송 가이드

### 매체별 추천 템플릿
| 매체 | 추천 | 이유 |
|------|------|------|
| 연합뉴스 | A안 | 국제부 기자 비중 높음, 속보 소스 각도 |
| 한겨레 | A안 | 국제/정치 비중 높음, 계엄 각도 |
| 중앙일보 | A안 or B안 | 섹션별 분류 |
| 조선일보 | A안 | 국제/정치 집중 |
| 동아일보 | A안 | 국제/정치 집중 |
| 매일경제 | B안 | 경제 전문, KScore 각도 |
| 한국경제 | B안 | 경제 전문, 투자 리스크 각도 |
| 전자신문 | C안 | IT 서비스/창업 스토리 각도 |
| 헤럴드경제 | B안 | 경제 전문 |
| 아시아경제 | B안 | 경제 전문 |

### 발송 주의사항
1. **하루 최대 50통** — 스팸 필터 회피 + 답장 관리 가능 범위
2. **{이름}과 {매체} 반드시 치환** — 개인화가 오픈율의 핵심
3. **오전 9~11시 발송** — 기자 이메일 확인 피크 시간
4. **팔로업은 1회만** — 3영업일 후 미답변 시 1회 리마인더
5. **수신거부 요청 즉시 처리**

### 성과 기대치
- 오픈율: 25-35% (일반 콜드이메일 대비 높음 — 제목이 구체적)
- 답장율: 5-8% (스토리 각도가 명확해서)
- 기사화: 2-5건 (1,198명 중)
- 서비스 가입: 50-100명
