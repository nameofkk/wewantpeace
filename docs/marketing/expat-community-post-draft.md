# 교민 커뮤니티 게시 초안 — 무료 주간 브리프 신청 받기

상태: 초안. 올리지 않았음. 올리는 건 사장님 몫.

목적: 해외 장기 거주자·잦은 출장자가 "사는 나라 한두 곳의 주 1회 요약"을 실제로 신청하는지 2주 동안 본다.
2주 통과 기준(진단 보고서 한국 트랙): 이메일 15명, 오픈 30%, 설문 5건 중 해외 체류·이해관계 60% 이상(투자 목적 문항 포함).
참고로 해외 트랙 기준은 이메일 20명(실방문 약 200명의 10%), 오픈 40%, 2호 재열람 25%, 답장 3건.
구독 수는 `python scripts/country_brief.py count` 로 본다 (source 별로 나뉨).

## 올릴 곳 후보와 확인할 것

- 이스라엘·레바논·UAE·대만 등 분쟁 인접국 한인회 게시판, 네이버 카페(나라별 교민 카페), 해외 거주 오픈채팅
- [ ] 각 커뮤니티의 홍보글 규칙(홍보 게시판 따로 있는지, 운영자 사전 허락 필요한지) 먼저 확인
- [ ] 한 커뮤니티에 한 번만. 여러 곳에 같은 글 반복 금지
- [ ] 링크의 ref 값을 커뮤니티마다 다르게: /brief?c=IL&ref=kr-il-cafe

## 본문

안녕하세요. 분쟁·안보 뉴스를 모아 정리하는 서비스를 운영하고 있습니다.

현지 뉴스는 현지어라 읽기 어렵고, 한국 뉴스는 큰 사건만 다루다 보니 "지금 여기서 무슨 일이 있고, 뭘 조심해야 하는지"를 한 번에 보기 어렵다는 이야기를 자주 들었습니다. 그래서 나라별로 일주일에 한 번, 짧은 요약 메일을 보내 보려고 합니다.

메일에는 이런 내용만 들어갑니다.
- 이번 주에 있었던 일 3~5개
- 각각 왜 중요한지, 다음에 무엇을 지켜보면 되는지
- 항목마다 몇 개 언론사가 같은 내용을 보도했는지 (한 곳만 보도한 소식은 따로 표시)

광고나 실시간 알림은 없고, 2주 동안은 제가 직접 읽고 써서 보냅니다. 받아 보시고 도움이 안 되면 메일 아래 링크로 바로 끊으시면 됩니다. 답장으로 "이런 것도 넣어 달라"고 주시면 반영하겠습니다.

신청: https://www.wewantpeace.live/brief?c=○○&ref=교민카페이름
(이메일과 나라만 받습니다. 확인 메일의 링크를 누르셔야 시작됩니다.)

## 첫 메일에 넣을 질문 (답장 유도)

"이번 주 요약에서 가장 쓸모 있었던 것 하나, 빠진 것 하나만 답장으로 알려 주세요."

설문(5건 목표) 문항 초안:
1. 지금 어느 나라에 계신가요? (거주 / 출장 / 가족이 거주 / 해당 없음)
2. 이 나라 소식을 챙겨 보는 가장 큰 이유는? (안전 / 일·사업 / 투자 / 가족 / 관심)
3. 지금은 어디서 소식을 보시나요? (현지 언론 / 한국 언론 / 대사관 공지 / 커뮤니티 / 기타)
4. 이 요약이 없어지면 아쉬울까요? (매우 / 조금 / 별로)
