## 1. 해시태그 전략

### 최적 사용법
- **개수**: 트윗당 **1-2개** (최대 3개)
- **위치**: 트윗 **끝부분**에 자연스럽게
- **유형**: 넓은 태그(#news)보다 **구체적 태그**(#UkraineConflict)

### 효과 데이터
- 해시태그 포함 → 리트윗 확률 **+33%**
- 1-2개 → 리트윗 **+21~33%**
- 3개 이상 → 인게이지먼트 **-17%** (역효과)

### 분쟁/OSINT/보안 뉴스 추천 해시태그 (로테이션)

| 카테고리 | 해시태그 |
|----------|----------|
| 분쟁 | `#UkraineWar` `#MiddleEast` `#IranIsrael` `#Geopolitics` |
| OSINT | `#OSINT` `#Intelligence` `#Intel` |
| 보안/군사 | `#Security` `#Defense` `#ConflictZone` |
| 뉴스 일반 | `#BreakingNews` `#WorldNews` `#GlobalSecurity` |

### 자동 알림 트윗에 적용 예시
```
🔴 SPIKE ALERT: Ukraine frontline escalation — 15 reports in 2h
Severity 8/10 | 5 independent sources

#OSINT #UkraineWar
```

```
⚡ Rising: Iran-Israel tensions surge — KScore 7.2
12 new events detected across 4 sources

#Geopolitics #MiddleEast
```

**규칙**: 토픽에 맞는 태그 1-2개를 자동으로 붙이되, 매번 같은 조합 반복 금지 (봇 패턴 감지됨)

## 3. 자동 게시 안전 가이드

### API 자동 게시 자체에 페널티 없음
공식 OAuth API를 통한 예약 게시는 허용됨.

### 페널티가 발생하는 것
- 봇 같은 행동 패턴 (일정한 간격, 반복적 포맷)
- 자동 좋아요/팔로우/리트윗 (= 즉시 섀도우밴)
- 시간당 100+ 좋아요, 50+ 리트윗, 30+ 답글

### 안전 범위
| 항목 | 안전 범위 |
|------|-----------|
| 일일 트윗 | 최대 **15-20개** |
| 트윗 간격 | 최소 **2-3시간** |
| 팔로우/언팔 | 하루 **50개 이하** |
| 신규 계정 초기 | 2주간 **하루 1-3개** |

### 섀도우밴 확인
- https://shadowban.yuzurisa.com/ 에서 확인 가능
- 복구: 24-72시간 모든 활동 중단 후 점진적 재개
